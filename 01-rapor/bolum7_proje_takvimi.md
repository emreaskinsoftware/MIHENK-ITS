# 7. PROJE TAKVİMİ

## 7.1. İş Paketleri ve Zamanlama

Proje takvimi, yarışma takviminde belirtilen tarihlerle (Teknik Rapor Teslimi: 24 Ağustos 2026, Mentörlük Süreci: 2-7 Eylül 2026, Final Sunumları Teslimi: 14 Eylül 2026, Canlı Sunum: 20 Eylül 2026, TEKNOFEST Şanlıurfa: 30 Eylül - 4 Ekim 2026) çelişmeyecek şekilde planlanmıştır.

| İş Paketi | Alt Faaliyet | Dönem |
|---|---|---|
| **İP1 — Temel Altyapı** | Simülasyon veri kümesi, arayüz iskeleti, API sözleşmesi | Tamamlandı |
| **İP2 — Teknik Rapor** | Bölüm yazımı, uyum denetimi, görsel üretimi, format kontrolü | Tamamlandı — 24 Ağustos teslim |
| **İP3 — Mentörlük Entegrasyonu** | Mentör geri bildirimlerinin mimariye işlenmesi | 2-7 Eylül 2026 |
| **İP4 — Model Olgunlaştırma** | Özetleme/tespit modellerinin gerçek akış verisiyle yeniden kalibrasyonu | 2-10 Eylül 2026 |
| **İP5 — Arayüz Tamamlama** | İçerik üretici, KVKK akışı, erişilebilirlik denetiminin son hâli | 2-10 Eylül 2026 |
| **İP6 — Kullanılabilirlik Testi** | 5 kullanıcıyla görev tabanlı test, bulguların uygulanması | 8-11 Eylül 2026 |
| **İP7 — Entegrasyon ve Uçtan Uca Test** | Arayüz-servis entegrasyonunun tamamlanması, demo senaryosu provası | 11-13 Eylül 2026 |
| **İP8 — Final Sunum Hazırlığı** | Sunum dosyası, demo videosu, canlı demo provası | 11-14 Eylül 2026 |
| **Kilometre Taşı — Final Sunum Teslimi** | | **14 Eylül 2026** |
| **Kilometre Taşı — Canlı Sunum** | | **20 Eylül 2026** |
| **İP9 — Festival Hazırlığı** | Stant materyali, canlı demo altyapısı | 20-29 Eylül 2026 |
| **Kilometre Taşı — TEKNOFEST Şanlıurfa** | | **30 Eylül - 4 Ekim 2026** |

Bu planlama, jürinin kolayca inceleyebileceği bir zaman çizelgesi olarak sunulmuştur; iş paketleri arasındaki bağımlılıklar (örn. İP6'nın İP5'e bağlı olması) sıralamaya yansıtılmıştır.

*[Kontrol maddeleri: iş paketleri/alt faaliyetler (2p) + kilometre taşları (1p) + görsel şema/tablo (1p) + yarışma takvimiyle uyum (1p)]*
